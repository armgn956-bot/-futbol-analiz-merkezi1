
Futbol maçlarını analiz eden ve Monte Carlo simülasyonuyla olası sonuçları hesaplayan bir web uygulaması.

Özellikler

* Maç ve lig listesi
* Takımların son maçlarına göre form analizi
* 50.000 simülasyon
* Galibiyet, beraberlik ve mağlubiyet olasılıkları
* Olası skor dağılımları
* Alt/üst ve karşılıklı gol olasılıkları

Kurulum

1. Node.js kurun.
2. Proje klasöründe npm install komutunu çalıştırın.
3. Gerekli API anahtarını ortam değişkenlerine ekleyin.
4. npm start komutuyla uygulamayı başlatın.
